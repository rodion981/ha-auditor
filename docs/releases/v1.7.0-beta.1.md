## English

This beta analyzes the confirmed upgrade path from the installed HACS version
to the available version. It counts intermediate releases and combines signals
for breaking changes, security fixes, deprecated options and new features
across the path. A minimum Home Assistant version is shown only when a release
explicitly states one. If the installed or target release cannot be matched
within the bounded GitHub lookup, the path is marked partial or unavailable.

Finding review now has a native Home Assistant to-do list. Check an item to
acknowledge it, or uncheck it to restore it to new. A select entity filters the
list by updates, archived repositories and inactive repositories. The release
also includes English and Ukrainian dashboard cards and critical-finding
automation examples.

The integration now owns its runtime manager through
`ConfigEntry.runtime_data`. The local Home Assistant 2026.9.2 suite passed 119
tests with 78.38% integration coverage. The GitHub CI and live Home Assistant
checks are separate beta validation steps.

## Українською

Ця бета аналізує підтверджений шлях від установленої версії HACS до доступної.
Вона рахує проміжні релізи й об'єднує сигнали про несумісні зміни, виправлення
безпеки, застарілі опції та нові можливості. Мінімальну версію Home Assistant
показано лише тоді, коли її явно вказано в описі релізу. Якщо межу шляху не
вдалося знайти в обмеженій перевірці GitHub, статус буде `partial` або
`unavailable`.

Для перегляду знахідок додано нативний список справ Home Assistant. Позначення
знахідки підтверджує її, зняття позначки повертає до стану `new`. Окрема
сутність фільтрує список за оновленнями, архівованими й неактивними
репозиторіями. Додано українську й англійську картки та приклади автоматизації
для критичних знахідок.

Менеджер інтеграції перенесено в `ConfigEntry.runtime_data`. Локальний набір
для Home Assistant 2026.9.2 пройшов 119 тестів із покриттям 78.38%. GitHub CI
та перевірка на живому Home Assistant є окремими етапами тестування бети.
