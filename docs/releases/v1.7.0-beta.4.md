## English

This beta fixes the concrete risk-excerpt failure reproduced on the installed
beta.3 with HACS 2.0.0 release notes.

- Prefer a dedicated risk section over introductory sentences that merely
  announce a list. Extract the actual list items instead of the introduction.
- Stop at the next section or separator, and never borrow unrelated feature
  text when a risk list is empty.
- Keep missing evidence empty while preserving the correct intermediate-release
  source rather than substituting unrelated target-release notes.
- Refresh cached beta.3 assessments with rules version 8. Finding IDs, review
  states, prerelease labels and path-count semantics remain unchanged.

The extraction was checked directly against the actual public HACS 2.0.0
release body. Hosted CI and installation/live validation remain separate gates.
This is a prerelease, not a stable-readiness claim.

## Українською

Ця бета виправляє випадок із примітками HACS 2.0.0, відтворений на встановленій
beta.3: замість конкретного ризику опис показував вступ до переліку змін.

- Розділ із ризиками має перевагу над вступним реченням. Опис бере самі
  пункти переліку, а не лише повідомлення про його наявність.
- Обробка зупиняється перед наступним розділом або розділювачем. Порожній
  перелік ризиків не заповнюється стороннім текстом про нові функції.
- Якщо конкретного опису немає, поле залишається порожнім, але правильне
  проміжне джерело зберігається. Текст іншого релізу не підставляється.
- Збережені оцінки beta.3 оновлюються за правилами версії 8. ID знахідок,
  статуси перегляду, позначки попередніх релізів і лічильники не змінені.

Виділення опису перевірене на справжньому публічному тексті релізу HACS 2.0.0.
CI та перевірка після встановлення є окремими етапами. Це попередній реліз,
а не підтвердження готовності stable.
