## English

This beta fixes two issues found while auditing twelve genuine pending updates.

- The sensor and both example dashboard cards now expose every assessed update,
  instead of silently stopping after ten. Recorder exclusions and individual
  upgrade-path detail limits remain unchanged.
- Optional-feature and conditional Home Assistant requirements are no longer
  promoted to integration-wide minimum versions. Ambiguous compatibility stays
  unknown; explicitly global requirements retain their version and release source.
- Assessment rules version 9 refreshes cached results without changing finding
  IDs, review states or the storage schema.

The actual Weather Radar Card release path was rechecked with public GitHub data:
its breaking-change evidence and fourteen-release path remain intact, while the
optional MapTiles requirement no longer becomes a global HA minimum.

## Українською

Ця бета виправляє дві проблеми, знайдені під час аудиту дванадцяти справжніх
доступних оновлень.

- Сенсор і обидві готові картки показують усі перевірені оновлення, без прихованого
  обмеження десятьма записами. Виключення з Recorder та обмеження деталей окремого
  шляху оновлення залишилися без змін.
- Умовна вимога або вимога окремої функції більше не стає мінімальною версією HA
  для всього компонента. За неоднозначних даних сумісність залишається невідомою.
  Явно загальні вимоги зберігають версію та посилання на реліз-джерело.
- Правила оцінювання версії 9 оновлюють кешовані результати без зміни ID знахідок,
  статусів перегляду чи схеми сховища.

Шлях Weather Radar Card повторно перевірено на справжніх даних GitHub: ризик
несумісних змін і шлях із чотирнадцяти релізів збережені, а вимога необов'язкової
функції MapTiles більше не видається за загальну вимогу до HA.

- Local Linux/Home Assistant 2026.9.2: 192 tests passed, 80.39% coverage.
- Local Windows: 169 tests passed; HA runtime tests are skipped on Windows.
- Ruff, formatting, strict card rendering and 12/120-update regressions passed.
- [Main CI](https://github.com/rodion981/ha-auditor/actions/runs/39320715529)

- The actual GitHub tag archive was checked for beta.5 metadata, rules 9 and
  the full update lists in the sensor and both example cards.
- This beta has not yet been installed or validated on the owner's Home Assistant.
