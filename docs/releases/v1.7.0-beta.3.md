## English

This beta makes update findings easier to understand without changing review
states or discarding intermediate-release risks.

- Risk summaries prefer the concrete breaking change or security fix instead
  of release introductions. When the strongest evidence comes from an
  intermediate release, its version and source link accompany the excerpt.
- Native finding to-do items and the English/Ukrainian example cards show
  that excerpt in its original language, without invented translation.
- Release paths mark prereleases using GitHub metadata, including releases
  whose version number has no beta suffix. Stable and prerelease counts are
  separate; the existing total remains backward compatible.
- Prereleases remain in risk analysis. The path is not a list of mandatory
  installations. Incomplete paths keep their counts unknown, not zero.
- Cached assessments refresh with rules version 7. Finding IDs and review
  states are preserved.

The updated cards are in `examples/dashboard.yaml` and
`examples/dashboard.uk.yaml`. Existing dashboards do not change automatically.

## Українською

Ця бета робить знахідки оновлень зрозумілішими, зберігаючи статуси перегляду
та аналіз ризику проміжних релізів.

- Короткий опис показує конкретну несумісну зміну чи виправлення безпеки,
  а не вступ релізу. Якщо головний ризик походить із проміжного релізу,
  поруч доступні його версія та посилання на джерело.
- Нативний список справ та українська й англійська картки показують цей
  уривок мовою оригіналу, без вигаданого перекладу.
- Попередні релізи позначені за метаданими GitHub, навіть якщо номер версії
  не має суфікса beta. Кількість стабільних і попередніх релізів розділена;
  загальний лічильник збережений для сумісності.
- Попередні релізи залишаються в аналізі ризику. Шлях не означає перелік
  обов'язкових установлень. Для неповного шляху кількість невідома, а не нульова.
- Збережені оцінки оновлюються за правилами версії 7. ID знахідок і статуси
  перегляду збережені.

Оновлені картки: `examples/dashboard.uk.yaml` та `examples/dashboard.yaml`.
Існуючі панелі автоматично не змінюються.
