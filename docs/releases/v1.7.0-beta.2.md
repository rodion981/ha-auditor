## English

This beta fixes three issues reproduced on a live Home Assistant installation:

- Descriptions of critical findings or GitHub-token security no longer become
  update-risk findings by themselves. Explicit incompatible-change and
  security-fix evidence still receives attention. Cached assessments refresh
  with the revised rules.
- A partial or unavailable upgrade path cannot clear an existing update-risk
  finding or downgrade its known severity. Repository-health checks remain
  independent, and resolved update conditions still require two clean checks.
- Clearing exclusions or the notification action in the options form now saves
  an empty value. Existing values remain visible when opening the form, and
  leaving the token field empty continues to preserve the saved token.

The release remains a prerelease. The beta.1 validation record documents the
controlled scenarios and the original failures; beta.2 is rechecked after
installation on the test Home Assistant instance.

## Українською

Ця бета виправляє три проблеми, відтворені на живому Home Assistant:

- Опис критичних знахідок або безпеки GitHub-токена сам по собі більше не створює
  ризик оновлення. Конкретні зміни далі отримують відповідний рівень уваги.
  Збережені оцінки перевіряються за новими правилами.
- Частковий або недоступний шлях оновлення не закриває існуючу ризикову знахідку
  й не знижує її відомий рівень. Перевірка стану репозиторію працює незалежно;
  для вирішення проблеми оновлення далі потрібні дві чисті перевірки.
- Очищення виключених репозиторіїв або дії сповіщення тепер зберігає порожнє
  значення. При відкритті форми поточні значення залишаються видимими, а порожнє
  поле токена зберігає раніше налаштований токен.

Це попередній реліз. Звіт beta.1 містить контрольні сценарії та початкові
помилки; beta.2 повторно перевіряється після встановлення на тестовий HA.
